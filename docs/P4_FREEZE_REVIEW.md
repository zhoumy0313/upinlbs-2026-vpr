# P4 最终评测前的冻结审查

本包是**开发结果之后、最终测试之前**的审查材料，不是预注册证明，也不是已经获得的最终结果。最终入口检查对应包的人工确认、代码与配置哈希、模型权重和全部输入产物；没有确认不会读取最终图像。

## 研究决策

主要模型对固定 CosPlace ResNet18/512 → EigenPlaces ResNet50/512；保留原始 CosPlace → DINOv2 ViT-S14 CLS/384 的负结果和同一套对照。协议允许的一次 B 替换已用完，不继续试模型。五维 A-only 输入、train-only标准化、C=1、无类权重、max_iter=2000、固定两个监督头和全部验证门限不再更改。

开发结论：原始模型对的净收益门控在全部预算零调用；替换模型对在25%调用时提高 A 的 R@1 4.33个百分点，但比同输入错误预测器低1.67个百分点。50%时两者相同。论文以实证比较和失效分析为当前候选贡献，不宣称净收益目标已胜出；最终结果只能检验这些发现能否迁移，不用于重新挑方案。

## 固定的最终实验矩阵

- Nordland-Part-2020：1750张summer图库；winter第1101–1750张，650个留出查询。主容差±5帧，额外±1/±10敏感性；这是同参考地图的区段留出，不是独立新路线。
- Gardens Point：200张day_right图库，200张night_right外部查询。严格对齐帧为主结果；±8只标为自定义正样本容差，不称为原教程GTsoft-ignore协议。
- 每个模型对评测此前全部50个策略：A/B单独、10%/25%/50%门限的净收益、错误预测（两头与单头）、间隔、去误伤头、去标准差，以及两组随机规则的完整0–4种子。Oracle只诊断，不部署、不计时。
- 门限和随机参数直接使用已保存的validation结果，不按测试调用率校准。随机对照匹配的是validation成本，测试实际调用率必须逐项报告；不能声称测试成本恰好相等。
- 真实batch1在线路径：每个模型对的A-only、B-only与25%预算下15个条件策略；另外实测10%/50%的净收益和两头错误预测。预热20查询，每种策略遍历完整查询3次，同步CUDA，保存每次真实A/B调用、候选、时延和Torch CUDA峰值。其余10%/50%对照只报告精度/调用，不虚构延迟。
- gallery建设、权重加载与索引初始化在在线计时之外；单独保存建库成本与向量空间。总查询时延含解码、预处理、实际模型前向、门控和全局检索。Torch分配峰值不是整个进程RSS或驱动占用。现有笔记本不锁GPU时钟，细小时差须谨慎解释。

## 冻结包与确认依据

`scripts/prepare_freeze_review.py` 生成新的 `outputs/freeze_review_*/selection.json`，记录Git提交、全部算法/评测/测试代码与科学配置SHA-256、模型source commit/完整权重与已加载state身份、清单、门控参数、门限及固定矩阵；作者信息单独待确认，不改变科学算法。有效协议副本明确B替换，原始 `configs/protocol.yaml` 的提出状态不被改写。
