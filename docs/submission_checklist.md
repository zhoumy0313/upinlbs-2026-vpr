# 投稿前逐项确认

## 正式要求
- [ ] 2026官方模板已下载，来源/日期保存。
- [ ] 确认6页是否含参考文献；当前按包含处理。
- [ ] 确认审稿匿名、纸型、出版社、稿件类别、语言和准确截止时间。
- [ ] 确认官网11月15日最终稿日期的解释，不将其当初稿延期。
- [ ] 需要注册、报告、PDF校验的条件已了解；不声称EI自动保证。

## 方法和证据
- [ ] 编码器冻结但选择器有监督训练，论文表述正确。
- [ ] SU/选择性匹配/SMR先例已明确讨论，未无依据宣称首次。
- [ ] 训练/验证/测试隔离、缓冲、图像ID及GT语义经人工核验。
- [ ] 没有B运行后才作“是否运行B”的伪条件调用。
- [ ] A-only、B-only、同成本随机、简单门限、同特征错误预测器均比较。
- [ ] 纠错/误伤/净Recall恒等式通过。
- [ ] 缓存模拟和真实在线延迟分开，包含A和门控开销。
- [ ] 不只挑最好种子，不删除失败图像，不用测试调参。
- [ ] Oracle只作为诊断，未称可部署方法。
- [ ] 无米级位姿、开放集安全、实机导航、VLA等越界宣称。

## 文稿
- [ ] 图表全部从锁定的metrics和逐查询数据生成。
- [ ] 每项结论指向实际实验；无TODO、虚构数字和不存在的引用。
- [ ] 正式PDF实际不超过页数限制；图可读、公式完整、字体正常。
- [ ] 作者/单位/基金及导师、合作者同意。
- [ ] 按实际出版/审稿要求披露AI使用，人工负责内容真实性。
- [ ] 已阅读版权/公开数据及模型许可证，不随包发布原始图像/权重。
- [ ] 投稿后下载系统内的稿件再核对，并保存回执和稿件ID。
