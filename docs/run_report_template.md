## 检查
- 同一图像顺序、同一正样本协议、同一测试集？
- 是否有数据泄漏，或使用 B 后才决定是否运行 B？
- 是否区分缓存评测与真实在线计时？
- 每一条结论能否定位到结果文件？

## 用户需要理解的内容
