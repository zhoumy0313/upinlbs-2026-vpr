# P3：原始模型对的开发证据

范围：Nordland-Part-2020 的 600 张 train 与 300 张 validation；没有编码或评测最终查询。A 为 CosPlace R18/512，B 为 DINOv2 ViT-S14 CLS/384；两者冻结。完整结果在 `outputs/p3_dinov2_stable_20261010_141000/gate_development/`，原先的边界数值问题和下载失败日志也保留。

## 已执行的选择器实验

五个 A 分数统计用于 train-only 标准化及逻辑回归。净收益为纠错概率估计减误伤概率估计；门限只由 validation 确定，预算为 10%、25%、50%，净收益门限最低为零。共保存 50 种策略的 train/validation 逐查询结果，其中随机策略完整报告种子 0–4，不挑最佳种子。

验证 A-only R@1 为 71.33%，B-only 为 51.67%。净收益与去标准差消融在三个预算均调用零次 B，R@1 均为 71.33%。这说明当前输入和固定拟合条件没有支持原始模型对的净收益门控改进，不能将零调用包装成精度提升。

同输入、同正则的 A 错误预测器在 10% 调用时纠错 8 次、误伤 4 次，R@1 为 72.67%；25% 时纠错和误伤各 17 次，R@1 为 71.33%；50% 时纠错 25 次、误伤 44 次，R@1 为 65.00%。选择器容量对照使用两头 error/correct，并额外报告单头 error；互补目标使两者排序一致，不能声称两头提供独立信息。

## 数值一致性修正

原实现把严格大于门限的边界直接放在某个验证分数上。矩阵乘法与逐图乘法约 1e-15 的差异会改变边界调用。现以相邻未选和选中分数的中点为门限；并列分数保守不超预算，净收益仍裁剪到零。修正发生于开发阶段；原日志和参数留存。28 个测试通过；全部 50 种策略、300 张验证图的批量与逐图决策差异为零。真实图像在线计时另行执行，不能以此缓存检查冒充模型延迟。

## 一次 B 替换的理由

原始 B 明显弱于 A，且净收益门控没有开发收益。依 `configs/protocol.yaml`，在任何最终测试之前使用唯一一次 B 替换机会：评估官方 EigenPlaces R50/512。原始模型对及全部负结果必须保留；不承诺替换后会改善，不再选择更多 B，不因最终结果改模型、标签或门限。

## 图像到排序的解释

1. 冬季 RGB 图像经过固定归一化和 224×224 缩放。
2. 冻结 A 输出一个 512 维单位向量，它不是地点编号或坐标。
3. 与 1750 个夏季图库向量逐一计算余弦相似度，形成一行分数。
4. 仅从 A 分数提取 top1、两个间隔、top10 均值和标准差。
5. 小选择器预测纠错与误伤的概率估计，并比较冻结门限。
6. 没触发就直接输出 A 排序；触发才真实运行 B，完全替换排序。
7. 真值只在离线训练标签和评测中出现，不作为在线选择输入。
8. ±5 帧属于本数据的检索评价容差，不能解释成米级定位。
