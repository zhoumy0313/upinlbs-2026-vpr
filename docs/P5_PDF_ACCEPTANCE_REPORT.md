## 给初学者的六步解释

1. 输入是一张查询照片，先转成RGB并按固定224像素规则预处理。
2. 冻结CosPlace把照片变成512维、单位长度的向量。
3. 查询向量与图库向量计算余弦相似度，分数降序形成候选排名。
4. 门控只读取A排名的五个分数统计，预测调用第二模型的纠错收益与误伤风险。
5. 超过已冻结门限时才计算B查询向量，返回B的完整图库排名；否则返回A排名。
6. 真值用于离线训练标签和评测，最终结果写入日志再进入论文；帧索引不等同于真实米级位置。
